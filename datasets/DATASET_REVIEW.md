## Selection summary

1. Collect **Egyptian device-viewpoint sequences first**: generic sources cannot teach reliable sidewalk obstructions such as tuk-tuks, vendor carts, missing paving, narrow passages, curb cuts, or local crossings. Use multiple capture routes/days and keep route/sequence IDs for split isolation.
2. Use **BDD100K** as an initial external transfer/evaluation source if rights fit and storage is increased/rechecked. Its detection label set overlaps the current YOLO classes, while drivable-area masks must not be treated as pedestrian-safe sidewalk labels.
3. Add **IDD** selectively for unstructured traffic and auto-rickshaws, prioritizing segmentation Part II or a detection subset only after staging storage and checking terms. IDD Lite is useful for converter smoke tests, not a meaningful high-performance training set.
4. Use **Mapillary Vistas** only after resolving version/license/storage; it may bring the most semantic richness but shouldn't replace local evaluation.
5. Keep **Cityscapes** as the existing SegFormer baseline/reference, not the main new training source.
